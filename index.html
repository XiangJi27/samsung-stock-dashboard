📥 นำเข้าสต็อกจาก Excel (Stock Snapshot Import)

รองรับไฟล์ Stock.xlsx (Sheet1 = ร้านเรา ชั้น 1 [f1], Sheet2 = สาขา ชั้น 2 [f2]) • เชื่อมโยง Exact P/N อัตโนมัติ

1 1. อัปโหลดไฟล์ (.xlsx)
2 2. ตรวจสอบข้อมูล & Diff
3 3. ยืนยัน Snapshot
📊

ลากไฟล์ Stock.xlsx มาวางที่นี่ หรือคลิกเพื่อเลือกไฟล์

ระบบจะตรวจ Header, จับคู่ Exact P/N, ดึงเฉพาะยอด On Hand และทำ Full Outer Join ระหว่าง Sheet1 และ Sheet2 โดยไม่แตะต้องราคาโปรโมชั่น

รองรับเฉพาะ .xlsx ต้องมี Sheet1 & Sheet2 ใช้คอลัมน์ On Hand แยก Price 99 เป็นราคาอ้างอิง

🌐 ซิงค์สต็อกสดจาก Google Sheet (CSV Web Sync)

ดึงข้อมูลสต็อกล่าสุดจากลิงก์ Google Sheet 'Publish to web' (CSV) โดยตรงผ่านเบราว์เซอร์ • ข้อมูลจะเข้า Diff Preview ให้ตรวจสอบก่อนยืนยันเสมอ

ซิงค์ล่าสุด: ยังไม่ได้ซิงค์
💡 วิธีทำลิงก์: ใน Google Sheet ไปที่ เมนู File → Share → Publish to web → เลือก Sheet สต็อก → เปลี่ยน 'Web page' เป็น Comma-separated values (.csv) → กด Publish แล้วคัดลอกลิงก์มาวาง
จำนวนสินค้าทั้งหมด 0 Unique Exact P/N
ยอดร้านเรา (ช1 / f1) 0 Sheet1 On Hand
ยอดสาขา (ช2 / f2) 0 Sheet2 On Hand
ยอดรวมสองชั้น 0 f1 + f2
สต็อกที่มีการเปลี่ยนแปลง 0 เทียบกับ Snapshot ปัจจุบัน
