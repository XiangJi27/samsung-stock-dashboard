## 1. ภาพรวมของระบบ (System Overview)
ระบบ **SAMSUNG Stock & Promotion Dashboard** ถูกออกแบบขึ้นเพื่อแก้ปัญหาและยกระดับการทำงานของพนักงานหน้าร้านสาขาอยุธยา ซิตี้ พาร์ค ชั้น 1 โดยมีเป้าหมายหลักคือ:
* **เลิกการเขียนนับสต็อกลงกระดาษ:** เปลี่ยนมาใช้ระบบกรอกตัวเลขออนไลน์ที่คำนวณผลต่าง (Diff) และตรวจจับสินค้าขาด/เกินได้ทันที
* **เทียบยอดจริงกับระบบ Nimbus อัตโนมัติ:** แสดงยอดคุมสต็อกของร้านเรา (ชั้น 1) แยกจากสาขาชั้น 2 อย่างชัดเจน
* **รวมข้อมูลโปรโมชั่นและวันหมดอายุ:** ไม่ต้องเปิดสลับไฟล์ Excel หลายไฟล์ มีระบบแจ้งเตือนวันหมดเขตแคมเปญ
* **ร่างรายงานสำหรับส่งเมล Outlook ในคลิกเดียว:** จัดรูปแบบข้อความตามมาตรฐานสาขาพร้อมส่งได้ทันที
* **สถาปัตยกรรม 95/5 Automation:** อนุมัติโปรโมชั่นที่ผ่านกฎสมบูรณ์อัตโนมัติ (~95%) และกักกันเฉพาะรายการเสี่ยงเข้า Exception Queue (~5%) เพื่อไม่ให้เกิดคอขวด
* **ดีไซน์ Obsidian Cyberpunk Dark:** สีดำสนิท ขอบนีออน สบายตา เปิดใช้งานบนจอหน้าร้านได้ตลอดทั้งวันโดยไม่เมื่อยล้าสายตา

## 7. ระบบตรวจนับสต็อกจริงเทียบระบบ & ร่างอีเมล Outlook (Reconciliation)

ปุ่ม **`📋 นับสต็อกจริงเทียบระบบ & ส่งเมล`** ด้านบนขวา:
1. ดึงยอดสต็อกตั้งต้นจาก Nimbus แบบ Real-time (คำนวณจาก Master Data สด ลบค่าคงที่ Hardcode ออกทั้งหมด)
2. พนักงานกรอกตัวเลขที่ตรวจนับจริงทางกายภาพใน 5 หมวดหลัก:
   * SmartPhone
   * Tablet
   * SmartWatch / Ring
   * Galaxy Buds
   * Adapter & Accessories
3. ระบบคำนวณผลต่าง (Diff) ทันที:
   * ผลต่าง = 0 ➔ สีเขียว `✓ ตรงกัน`
   * ผลต่าง < 0 ➔ สีแดง `⚠️ ขาด X เครื่อง`
   * ผลต่าง > 0 ➔ สีส้ม `⚠️ เกิน X เครื่อง`
4. ร่างเนื้อหาอีเมลตามฟอร์แมตมาตรฐานสาขาอยุธยา ซิตี้ พาร์ค พร้อมปุ่มคลิกเดียวส่งเข้า Outlook หรือคัดลอกลง Clipboard

## 9. สถาปัตยกรรม 95/5 Risk Automation & ศูนย์ Exception Review

ระบบเปลี่ยนผ่านจากกระบวนการเดิมที่ต้องรอคนอนุมัติทั้งไฟล์ (Human Bottleneck) และระบบ AI เดาราคา มาสู่โมเดล **95/5 Automation**:

```
Excel โปรโมชั่นใหม่
       ↓
AI อ่านและแปลงเป็นโครงสร้างมาตรฐาน (Standard Schema)
       ↓
ระบบตรวจสอบด้วยกฎตายตัว 7 ข้อ (Rule Engine Validation)
       ↓
┌─────────────────────────┬─────────────────────────┬─────────────────────────┐
│     🟢 ความเสี่ยงต่ำ     │    🟡 ความเสี่ยงกลาง     │     🔴 ความเสี่ยงสูง     │
│   Auto-Publish อัตโนมัติ │   Publish พร้อมคำเตือน   │   ไม่ Publish (กักกัน)  │
│       (~93.5% / 216 รายการ)│     (~4.8% / 11 รายการ)   │     (~1.7% / 4 รายการ)  │
└─────────────────────────┴─────────────────────────┴─────────────────────────┘
```

### หลักการสำคัญ
* **AI ไม่ใช่ผู้อนุมัติราคา:** AI มีหน้าที่แปลงเอกสาร ส่วนระบบกฎตายตัว (Rules Engine) เป็นผู้ตัดสินว่าสามารถเผยแพร่ได้หรือไม่
* **ไม่รออนุมัติทั้งไฟล์:** รายการที่ถูกต้อง 216 รายการขึ้นจอขายตามเวลา ส่วน 4 รายการที่มีข้อผิดพลาดถูกส่งเข้า Exception Queue ไม่ทำให้ระบบทั้งหมดหยุดชะงัก
* **กักกันราคาผิดพลาดเด็ดขาด (Zero #ERROR!):** รายการที่พบ `#ERROR!` หรือสูตรผิดพลาดใน Excel เช่น S25 Ultra ในชีต Tablet Acc จะถูกซ่อนราคาโปรโมชั่น แสดงสถานะ `⚠️ รอตรวจสอบข้อมูลต้นทาง` พร้อมอ้างอิงราคาปกติ SRP เท่านั้น

## 10. สถาปัตยกรรมฐานข้อมูล 3 ชั้น (3-Layer Architecture)

1. **ชั้นที่ 1 (Raw Import):** เก็บข้อมูลดิบจาก Excel โดยไม่ดัดแปลงต้นฉบับ
   * `sourceFile`, `sourceSheet`, `sourceRow`, `rawModel`, `rawRrp`, `rawDiscount`, `rawNetPrice`, `rawCoupon`, `rawRemark`, `importedAt`
2. **ชั้นที่ 2 (Validated Promotions):** จัดโครงสร้างและตรวจสอบด้วยกฎ 7 ข้อ
   * `promoId`, `sku`, `saleMode`, `sfPlusEligible`, `tradeUpEligible`, `riskLevel` (`LOW`, `MEDIUM`, `HIGH`), `status` (`PUBLISHED`, `WARNING`, `BLOCKED`), `confidenceScore` (0-100)
3. **ชั้นที่ 3 (Published Promotions):** ข้อมูลที่พร้อมขึ้นจอ Dashboard หน้าร้าน
   * `promoId`, `sku`, `saleMode`, `displayPrice`, `couponCode`, `conditions`, `effectiveStart`, `effectiveEnd`, `version`

## 11. กฎการตรวจสอบตายตัว 7 ข้อ (Strict Rule Engine)

| ลำดับ | กฎการตรวจสอบ | รายละเอียดและการคำนวณ | สถานะผลการตรวจ |
| :---: | :--- | :--- | :---: |
| **1** | **สมการลดบาทตายตัว** | `RRP - discountValue === netPrice` | **PASS ✓** (182 รายการ) |
| **2** | **สมการลดเปอร์เซ็นต์** | `Math.round(RRP * (1 - Rate)) === netPrice` (Watch8 BT ฿12,530) | **PASS ✓** (32 รายการ) |
| **3** | **ความขัดแย้งสินเชื่อ SF+** | ตรวจจับกรณีระบุ `sfPlusEligible = true` แต่มีข้อความ "ห้ามร่วม SF+" | **PASS ✓** (0 ข้อขัดแย้ง) |
| **4** | **โปรโมชั่นนักศึกษาห้ามซ้อน** | โหมด STUDENT ห้ามซ้อนคูปองหน้าร้านหรือ Trade Up | **PASS ✓** (บังคับใช้) |
| **5** | **Zero #ERROR! กักกันราคา** | ตรวจพบ `#ERROR!` ในชีต Tablet Acc ➔ กักกันทันที 4 SKU | **PASS ✓** (กักกันสมบูรณ์) |
